⌨️ Hand-Scanner bereit – einfach losscannen, kein Feld antippen nötig.

Noch keine Filamente. Scanne den QR-Code einer Spule – mit dem Hand-Scanner oder der Kamera.

Hilfe
  • Einlagern: Jeder Scan legt eine Spule an. Ein Code, den die App noch nicht kennt, wird als Sorte „ohne Details“ angelegt – Material und Farbe trägst du einmal ein, danach erkennt die App jede weitere Spule mit diesem Code sofort.
  • Ausbuchen: Leere Spule scannen – eine Spule dieser Sorte verschwindet (zuerst eine angebrochene). Oder in der Liste auf „−“ tippen.
  • Hand-Scanner (USB oder Bluetooth) arbeiten wie eine Tastatur. Stelle sie auf das Tastaturlayout deines Geräts (meist Deutsch) und auf „Enter“ nach jedem Scan.
  • Kamera: Code ins Bild halten. Derselbe Code zählt erst wieder, wenn er kurz aus dem Bild war – so kannst du mehrere gleiche Spulen nacheinander zeigen.
  • Die Daten liegen in diesem Browser. Über ☁ gleichst du sie verschlüsselt mit deinen anderen Geräten ab (über einen geheimen Gist in deinem GitHub-Konto). „Sicherung speichern“ lädt zusätzlich eine Datei herunter.

Geräte abgleichen

Rolle legt deinen Bestand verschlüsselt in einem geheimen Gist in deinem GitHub-Konto ab. Lesen kann ihn nur, wer dein Kennwort kennt – auch GitHub nicht.

Auf einem anderen Gerät schon eingerichtet?

Dort auf ☁ und „Weiteres Gerät verbinden“ tippen, dann den Code hier scannen.

Zum ersten Mal einrichten
  1. Zugangsschlüssel bei GitHub erstellen ↗ Das Häkchen „gist“ ist schon gesetzt. Ablaufdatum wählen (z. B. „No expiration“), unten „Generate token“ tippen und den Schlüssel kopieren.

Neuen Zugangsschlüssel erstellen ↗

Auf dem anderen Gerät Rolle öffnen, auf ☁ und „Code scannen“ tippen und diesen Code scannen. Danach fragt es nach dem Kennwort.

Der Code enthält deinen GitHub-Zugangsschlüssel (nicht das Kennwort). Zeig ihn niemandem sonst.

Mehr

Das Kennwort selbst bleibt nirgends gespeichert, auf den Geräten liegt nur der daraus berechnete Schlüssel. Ohne Kennwort lässt sich der Bestand nicht wiederherstellen – auch nicht von GitHub.

Ein neues Gerät ohne Code einrichten: Zugangsschlüssel bei GitHub erstellen, einfügen, Kennwort eingeben. Rolle findet die Ablage selbst.
